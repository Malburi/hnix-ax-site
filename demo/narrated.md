# 해설 시연 영상 — 운영 · 데이터와 통제 · AX-NAVI CLI

목소리 해설이 붙은 시연 영상 세 편이다. 시연회에서 틀어 두고 설명 없이 보여 줄 수 있게 만들었다. 깨끗하게 새로 띄운 시연 환경(시험 데이터 없음)에서 실제 제품을 조작하며 녹화했다. 판은 AX Platform 0.9.3 · PMS-X 1.3.17 · AX-DataLake 0.6.0 · AX-NAVI IDE 1.2.8 이다(2026-11-15 다시 녹화 — 서비스 요청 분류·배정 한 칸, 흐름의 답변 초안, 레이크 파일 목록, 플랫폼·레이크 화면 글꼴 Pretendard, 서비스 요청 상세는 요청자 개인정보를 가려 승인 없이 읽음). ③ 은 AX-NAVI CLI 1.0.1(엔진 0.1.0-alpha.27)이다.

- 해설은 사내 PC에서 돌린 음성 합성으로 만들었다. 장면마다 해설이 끝날 때까지 화면이 머문다.
- AI 답을 기다리는 구간(창구 답 · 흐름 실행 · 분류 의견 · IDE 에이전트 · 지식 문서 초안)은 빨리 감았다. 답 자체는 사내 로컬 모델이 그 자리에서 낸 것이다.
- 등장 인물과 회사는 시연용으로 만든 것이다(김현업 · 서운영 · 이개발, ○○공사 인사팀).

## ① 운영 — 현업 문의 한 건이 지식이 되기까지 (6분 40초)

<video controls preload="metadata" poster="video/narrated/ops.jpg" src="video/narrated/ops.mp4" style="width:100%;border-radius:10px;background:#0f1d2b"></video>

| 순서 | 화면 | 보여 주는 것 |
|---|---|---|
| 1 | 현업 창구(김현업) | "급여 계산 배치가 늦어진 원인"을 AX-DataLake에 모아 둔 **장애 보고서**를 근거로 답한다. 보고서 속 전화번호는 레이크에 넣을 때 이미 가려졌고, 창구는 레이크를 분석가 권한으로만 읽는다 |
| 2 | 현업 창구 → 담당자에게 넘기기 | "사원 조회에 퇴사자가 같이 나와요"는 운영 매뉴얼로 안내하고, 그래도 안 풀리면 대화 기록과 함께 **PMS-X 서비스 요청**으로 접수된다 |
| 3 | 업무 자동화 · 승인함 | 감시 트리거가 새 요청을 '서비스 요청 분류·처리' 흐름에 넣는다. 사내 모델 분류 → 문의면 지식 문서를 찾아 근거를 단 **답변 초안** → 사람 확인에서 멈추고, 운영 책임자가 승인함에서 답변 초안을 읽고 승인한다(실행한 사람은 스스로 승인 못 함) |
| 4 | PMS-X(서운영) | 분류 의견이 유형·우선순위·대상 화면·담당 후보를 '다음 단계' 칸에 채우고 → 한 번에 **담당 배정** → 처리 시작, 대상 화면을 As-Is 메뉴 트리와 잇고, 구현 명세 내보내기와 As-Is 화면 뷰어 |
| 5 | AX-NAVI IDE(이개발) | 요청 번호만 주고 맡긴다. 조회 도구는 바로, 파일 수정만 개발자 확인 — 요청 본문을 읽고(요청자 이름·연락처는 허브가 가림) 이름 조회 SQL 에 재직 조건 |
| 6 | PMS-X 처리 완료 · 지식 문서 | 처리 내용을 남기고 닫으면 처리 기한 준수율·월간 보고에 들어간다. 끝난 요청으로 지식 문서 초안(증상·원인·조치)을 만들어 등록 |

## ② 데이터 · 통제 · 도입 구성 (3분 34초)

<video controls preload="metadata" poster="video/narrated/gov.jpg" src="video/narrated/gov.mp4" style="width:100%;border-radius:10px;background:#0f1d2b"></video>

| 순서 | 화면 | 보여 주는 것 |
|---|---|---|
| 1 | AX-DataLake 대시보드(분석가) | '장애 현황' — 전체 900건 중 자기 계열사 300건만. 열 때마다 보는 사람 권한으로 다시 조회 |
| 2 | AI 분석 | "시스템별 장애 건수는?" → 데이터 담당자가 검증해 둔 질의를 모델 없이 그대로 써서 늘 같은 답 |
| 3 | 레이크 문서(엔지니어) | 장애 보고 PPT · 회의록 · 운영 실적 엑셀 · 스캔 점검표 — 개인정보는 넣는 순간 가림 |
| 4 | 플랫폼 문서 검색(이개발) | 플랫폼 문서와 **레이크 문서**가 한 결과에. 권한 없는 '경영 검토' 문서는 나오지 않는다 |
| 5 | LLM 게이트웨이 요청 기록 | 누가 · 어느 기능에서 · 어느 모델을 · 토큰과 시간. 기밀 등급은 사내 모델로만 |
| 6 | 현장 연결 점검 | 기반 + 선택 모듈 여덟 개(끄면 메뉴·API·도구에서 빠짐) · 레이크 문서 연결 상태 |
| 7 | 레이크 로그인 · 사용자 관리 | 자체 계정이 기본, **사내 AD·SSO 는 선택** — 사내 계정으로 등록하거나 첫 로그인 때 그룹으로 역할·소속을 정함 |

## ③ AX-NAVI CLI — 터미널에서 레거시 길 찾기 (3분 28초)

<video controls preload="metadata" poster="video/narrated/cli.jpg" src="video/narrated/cli.mp4" style="width:100%;border-radius:10px;background:#0f1d2b"></video>

| 순서 | 화면 | 보여 주는 것 |
|---|---|---|
| 1 | `axnavi login` → 브라우저 | 설치본에는 엔진이 없다. 승인 주소·확인 코드 → 플랫폼에 사내 계정으로 로그인해 **이 기기 승인** → 엔진과 사내 게이트웨이 연결을 받는다 |
| 2 | `axnavi whoami` | 사람 · 사용 허가 · 엔진 판 · 사내 모델(게이트웨이) · 사용량 기록 |
| 3 | `axnavi index build` · `index coverage` | AI 없이 인사시스템 47개 파일의 지도 — 화면 · 자바 · 매퍼 SQL · 테이블 · 호출 관계, 자동 변경 가능 72% |
| 4 | `axnavi` 대화형 모드 | 프로젝트 · 인덱스 상태 · 실행 경로(사내 게이트웨이), `/agents` 에이전트 19종 |
| 5 | `git diff` → `axnavi review` | 정렬 기능을 넣으며 MyBatis `${}` 로 컬럼을 붙인 변경 → **STOP**(SQL 인젝션 · OWASP A03 · CWE-89), 위치와 고치는 법 |
| 6 | `$LASTEXITCODE` → 4 | CI 에 넣으면 머지가 막힌다(GO 0 · HOLD 3 · STOP 4) |
| 7 | 플랫폼 › AX-NAVI 사용 허가 › 기기 | 방금 승인한 기기 — 끊으면 그 PC 의 CLI 는 바로 잠긴다 |

> ③ 의 터미널 출력은 실제 명령이 낸 그대로다. 시연 PC 의 작은 CPU 모델(4B)은 코드 탐색 질문의 답이 부정확해 '질문 → 답' 장면은 넣지 않았다 — 에이전트 질문·수정은 ① 의 IDE 장면과 같은 엔진이다. 녹화 PC 의 이름·폴더는 `DEV-PC01` · `W:\` 로 바꿔 보이게 했다.

> ② 의 레이크 로그인(SSO 단추)과 사용자 화면의 '사내 계정'은 시연 레이크에 예시 AD·SSO 설정만 넣고 찍은 모습이다(실제 디렉터리 연결 없음). 설정 방법은 [제품 조합과 함께 설치할 때](/getting-started/together.md)와 매뉴얼의 계정 절에 있다.
