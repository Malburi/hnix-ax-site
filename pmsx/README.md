# PMS-X

PMS-X는 레거시 화면의 버튼 하나가 어떤 함수·API·SQL·테이블로 이어지는지 보여 주는 SI·SM 통합 프로젝트 관리 시스템이다. 구축(SI)에서 분석한 화면 자산이 운영(SM)으로 그대로 넘어가, SR을 받으면 그 화면과 영향 범위를 바로 본다.

## 왜 필요한가

| 기존 방식 | PMS-X |
|---|---|
| 화면정의서·프로그램 사양서를 사람이 엑셀로 작성 | 소스·DB·화면을 **자동 수집**해 뷰어로 보고, 산출물은 **자동 출력** |
| 테이블 하나 바꿀 때 영향 범위를 grep으로 추측 | **영향도 분석**: 테이블·컬럼·함수 → 영향 화면·버튼·배치·최근 SR·담당자 |
| SI가 끝나면 분석 자산이 흩어지고 SM은 처음부터 다시 파악 | **SI → SM 인수인계** 한 번으로 화면 분석·추적성·담당자를 운영 프로젝트로 이관 |
| 일정·인력·품질·운영 도구가 제각각 | WBS·인력·산출물·품질·SR·SLA를 한 시스템에서, 같은 화면 자산에 연결 |
| 클라우드 SaaS는 고객사 폐쇄망에 못 들어감 | **단일 jar + 내장 JRE 오프라인 설치 패키지**, 외부 호출 0건 |

## 기능 영역

| 영역 | 주요 화면 |
|---|---|
| **As-Is 분석** | 화면 분석 뷰어(코드 순서도 · 통합 추적 · 데이터 흐름도 · 한국어 설명 · 트리거), 분석 진척, CRUD, 화면 이동 맵, 영향도, 산출물 출력, 현행 프로그램 대장 |
| **DB · PL/SQL** | DB 오브젝트(트리거 · 뷰 · 패키지 · 프로시저 · 시퀀스 · 시노님), 테이블 정의서 품질 배지, 확인할 화면, ERD |
| **일정** | WBS·간트(공정준수율), 통합 일감 칸반, 베이스라인, 주간보고, PM 대시보드, 공지사항 |
| **인력·공수** | 인력 풀, 투입 계획·히트맵, 작업 배분, 작업일지, MM 정산 |
| **산출물·추적성** | 산출물 대장, 요구사항, 추적성 매트릭스, 감리 체크리스트, 프로젝트 위키 |
| **품질** | 이슈, 리스크, CR, 테스트(절차 · 실패 시 결함 자동 등록), 결함, 회의록(액션아이템) |
| **SM 운영** | SR, 장애, 문제, 변경·배포, 정기 작업, 운영 자산, KB, SLA, 월간 운영보고, 고객 포털, 경보 접수 |
| **AI 보조** (선택) | SR 분류·배정 추천, KB 초안, 버튼·함수 설명 초안 |
| **관리** | 사용자·역할, 공통코드·용어 사전, 방법론, 엑셀 템플릿, 감사 로그, 라이선스 |

## 기술 구성

| 구성 | 기술 |
|---|---|
| 웹 | Vue 3, Vuetify 3, TypeScript, ECharts, Vue Flow. 외부 CDN 0건, 라이트·다크 |
| 서버 | Spring Boot 3, Java 21, 웹을 포함한 단일 jar |
| DB | PostgreSQL · Oracle 12c+ · Tibero · SQL Server 2016+ · H2 (실행 직전 SQL 방언 번역) |
| 수집기 | Python, tree-sitter, sqlglot, Playwright(설치된 Chrome·Edge), pywinauto. 단일 exe |
| 배포 | jlink JRE 21 포함 오프라인 패키지, 오프라인 라이선스(Ed25519) |
| 인증 | 로컬 계정, LDAP·AD, 5회 실패 잠금, 역할 기반 권한, 감사 로그 |
