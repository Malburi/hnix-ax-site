# 설치 가이드 — 개인 PC

개발자·운영자 PC 에 **AX-NAVI IDE** 를 깔고 회사 HNIX AX 플랫폼에 잇는다. 설치 파일 하나(`HNIX-AX-PC-Setup-<판>.exe`)를 실행하고, 브라우저에서 한 번 승인하면 끝이다. 키나 환경 변수를 손으로 넣지 않는다.

서버는 [서버 PC 설치 가이드](https://malburi.github.io/hnix-ax-site/#/getting-started/install-server)로 먼저 깔려 있어야 한다.

## 1. 준비

| 항목 | 기준 |
|---|---|
| OS | Windows 10/11 64비트 |
| 디스크 | 여유 2GB |
| 권한 | 관리자 권한 필요 없음(내 계정에 설치) |
| 회사 플랫폼 | 주소(예 `http://ax-test.corp.local:8700`)와 내 계정 — 관리자에게 받는다 |
| AX-NAVI 사용 허가 | 관리자가 플랫폼 **AX-NAVI › 사용 허가**에서 허가해 줘야 로그인된다 |
| 선택 | Git for Windows(변경 리뷰), Claude 구독(Pro·Max·Team·Enterprise) |

## 2. 설치 파일 받기

1. 브라우저로 회사 플랫폼에 로그인한다.
2. 왼쪽 메뉴 **내 연결 설정** › **1 개인 PC 설치** › **개인 PC 설치 파일 받기**.

<figure><img src="img/platform-setup.png" alt="내 연결 설정 — 개인 PC 설치, 이 서버에 연결, 확인 세 단계"><figcaption>내 연결 설정. 설치 → 연결 → 확인 세 단계다.</figcaption></figure>

관리자가 파일로 나눠 줬다면 그것을 쓴다(같은 파일이다).

## 3. 설치

`HNIX-AX-PC-Setup-<판>.exe` 를 실행한다.

| 화면 | 할 일 |
|---|---|
| 설치 위치 | 기본 `%LOCALAPPDATA%\Programs\AX-NAVI IDE` 그대로 |
| 추가 작업 | 바탕 화면 바로가기, 터미널 명령 `axnavi-ide`(PATH) — 원하는 것만 |
| **회사 플랫폼 연결** | '내 연결 설정'에 보이는 플랫폼 주소를 넣는다. 비워 두면 IDE 를 처음 열 때 묻는다 |

설치가 끝나면 AX-NAVI IDE 가 열린다. 한국어 화면과 언어 팩은 설치 프로그램이 맞춘다.

## 4. 연결 — 브라우저에서 한 번 승인

1. IDE 가 열리면 오른쪽 아래에 **'…에 로그인해 이 PC 를 승인받으세요'** 가 뜬다 → **로그인**.
   - 플랫폼 웹 **내 연결 설정 › 2 이 서버에 연결 › AX-NAVI IDE 에서 열기**를 눌러도 된다. IDE 가 '이 플랫폼에 연결할까요?'를 물으면 주소를 확인하고 **연결**.
   - 주소를 넣지 않았으면 IDE 왼쪽 아래 상태 표시줄의 **AX-NAVI 로그인**을 눌러 주소를 넣는다.
2. 브라우저에 승인 화면이 열린다(로그인돼 있지 않으면 로그인). 코드와 PC 이름을 확인하고 **승인**.
3. IDE 상태 표시줄에 **AX-NAVI · 내 이름** 이 보이면 끝이다. '내 연결 설정 › 3 확인'에도 내 PC 가 나온다.

## 5. 자동으로 설정되는 것

승인하면 IDE 가 플랫폼에서 이 PC 전용 연결을 받아 스스로 맞춘다. 이 PC 를 끊거나 허가가 회수되면 플랫폼이 이 키들을 끄고, IDE 도 지운다.

| 무엇 | 어디에 | 하는 일 |
|---|---|---|
| 사내 모델 | IDE 의 AI 연결 'AX-NAVI 사내 게이트웨이' | 구독이 없어도 사내 모델로 채팅·코드 작업(비용은 조직) |
| MCP 허브 `hnix-ax` | IDE 채팅의 MCP 서버 | 지식 문서·매뉴얼·런북·서비스 요청·**에이전트**를 채팅에서 도구로 |
| 사용량 기록 | 플랫폼 사용량·비용 | 작업 요약(본문 없이 시간·결과·토큰) |
| AX-NAVI 엔진·스킬 | IDE | 변경 리뷰·보안 점검·코드 색인·`/find` 같은 스킬 |
| **Claude Code**(PC 에 있으면) | `~/.claude/settings.json`, `~/.claude.json` | 사용량 전송(토큰·비용·도구 이름만, 본문 없음)과 MCP 허브 `hnix-ax` — 터미널의 Claude Code 에서도 같은 자산을 쓴다 |

Claude Code 를 IDE 보다 나중에 깔았으면 IDE 를 한 번 다시 열면 맞춰진다. 끄려면 IDE 설정 `axnavi.claudeCode.autoConfigure`.

## 6. Claude 구독이 있으면

PC 에 Claude Code 를 깔고 터미널에서 `claude` 를 한 번 실행해 본인 계정으로 로그인한다. IDE 가 구독을 먼저 쓰고, 안 될 때만 사내 모델로 넘어간다. 구독 자격 증명은 회사 서버로 가지 않는다.

## 7. 써 보기

IDE 오른쪽 채팅에서:

| 해 볼 말 | 쓰는 도구 |
|---|---|
| "사원 조회에 퇴사자가 나오는 문제와 비슷한 지식 문서를 찾아줘" | `pmsx__similar` → `pmsx__kb` |
| "운영 매뉴얼에서 계정 잠금 해제 방법을 찾아줘" | `docs__search` |
| "방금 정리한 조치를 '운영 매뉴얼'에 문서로 저장해줘" | `docs__save` |
| "SR-0042 처리 내용으로 지식 문서를 등록해줘" | `pmsx__sr` → `pmsx__kb_create` |
| "경보 진단 에이전트에게 '야간 배치 실패' 원인을 물어봐줘" | `agents__run` |

쓰기 도구는 회사 정책에 따라 승인을 기다릴 수 있다(플랫폼 승인함).

## 8. 내 에이전트 만들기

플랫폼 **에이전트** › **내 에이전트 만들기**. 지시문, 모델, 쓸 도구(예 `docs__search`, `pmsx__*`)를 적는다.

- 만든 에이전트는 **나만** 보고 실행한다. IDE·Claude Code 에서도 `agents__run` 으로 부른다.
- 팀과 함께 쓰려면 '팀에 공유 요청' → 관리자가 승인하면 워크스페이스 사람들이 쓴다.
- 어떤 도구를 적어도 실행한 사람의 권한을 넘지 못한다.

## 9. 판 올리기 · 옮기기 · 지우기

| 할 일 | 방법 |
|---|---|
| 새 판 | 새 `HNIX-AX-PC-Setup` 을 실행해 덮어 설치(주소·로그인은 그대로) |
| 다른 서버로 | 상태 표시줄 **AX-NAVI** › 다른 플랫폼 주소로 연결 |
| 연결 키 새로 받기 | 상태 표시줄 **AX-NAVI** › 연결 다시 받기(지난 키는 꺼진다) |
| 로그아웃 | 상태 표시줄 **AX-NAVI** › 로그아웃 — IDE·Claude Code 에 넣은 연결을 지운다 |
| 제거 | '앱 및 기능' › AX-NAVI IDE |

예전 판(zip + `설치.cmd`)으로 깐 PC 도 새 설치 파일로 덮어 설치하면 된다. 예전에 손으로 넣은 환경 변수(`HNIX_AX_*`, `AXNAVI_OPENAI_*`)가 있으면 그 값이 먼저 쓰이니 지운다.

## 10. 자주 막히는 곳

| 증상 | 확인 |
|---|---|
| 설치 파일·IDE 가 실행되자마자 지워짐 | 사내 보안 프로그램 — 관리자에게 [서버 PC 설치 가이드](https://malburi.github.io/hnix-ax-site/#/getting-started/install-server) 6번(게시자 예외)을 요청 |
| '…에 닿지 않습니다' | 이 PC 브라우저에서 `http://<플랫폼>/healthz` 가 열리는지 — 사내망(VPN)·프록시 예외 |
| 승인 화면에서 '사용 허가가 없습니다' | 관리자에게 AX-NAVI 좌석 허가를 요청 |
| '기기는 2대까지입니다' | 플랫폼 **내 AX-NAVI 기기**에서 안 쓰는 PC 를 끊는다 |
| 승인 코드가 만료됨 | 10분 안에 승인해야 한다 — IDE 에서 다시 로그인 |
| 채팅에서 허브 도구가 안 보임 | 상태 표시줄 **AX-NAVI** › 연결 다시 받기 |
