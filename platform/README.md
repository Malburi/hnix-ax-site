# AX Platform

AX Platform은 HNIX AX 제품군이 함께 쓰는 AI 기반이다. 모델 호출, 도구 호출, 사용량, 승인, 문서 검색을 한곳에서 다룬다. 기존 도구(PMS-X, AX-NAVI)는 고치지 않고 커넥터로 연결한다.

## 기반과 선택 모듈

설치본은 하나다. **기반**은 늘 켜져 있고, **선택 모듈**은 현장마다 설정 파일의 `modules`에서 켜고 끈다(기본은 모두 켜짐).

| 구분 | 들어 있는 것 |
|---|---|
| 기반 | LLM 게이트웨이 · AI 사용 현황(사용량·비용) · MCP 허브와 승인함 · 문서 검색 · AX-NAVI 사용 허가·조직 설정 · 워크스페이스 채팅 · 업무 흐름 개선 · 사용자·감사·알림·현장 연결 점검 |
| `automation` 에이전트·자동화 | 에이전트 실행기 · A2A · 자동화 흐름 · 자동 실행(웹훅·예약·감시) · 런북 — 서로를 불러 한 모듈 |
| `desk` 현업 창구 | 창구 화면 · 메신저·메일 · 담당자 접수 |
| `itsm` 고객 ITSM 연동 | ServiceNow·Jira·일반 REST 동기화 · 창구의 'ITSM 연결' 접수 |
| `biz` 업무 시스템 연결 | SAP·Salesforce·Microsoft 365·네이버웍스·사내 REST 도구 |
| `voice` 음성 | 채팅·현업 창구의 말로 묻기·읽어 주기 |
| `productivity` 생산성 보고서 | 커밋·서비스 요청·AI 관여 보고서 · 저장소 웹훅 |
| `enterpriseAi` 전사 AI 관측 | 외부 AI 사용량 · AI 자산 대장 |
| `evaluation` 평가 | 모델 평가 · 에이전트 평가(`automation`도 켜져 있어야) |

```yaml
modules:
  itsm: false     # 고객이 ITSM을 쓰지 않는 현장
  voice: false
```

끈 모듈은 메뉴·바로 가기·대시보드·통합 검색에서 빠지고, API·웹훅은 `404 module_disabled`로 답하며, 내장 도구와 예약 작업도 멈춘다. 자료는 지우지 않으므로 다시 켜고 재시작하면 그대로 돌아온다. 지금 켜진 모듈은 **관리 › 현장 연결 점검**의 '기능 모듈'에서 본다. 다른 제품과 묶는 법은 [제품 조합과 함께 설치할 때](/getting-started/together.md)에 있다.

## 한 프로세스, 한 포트

```text
http://<서버>:8700
  /           웹 (Vue 3, 한국어)
  /api/v1     관리 REST API (JWT)
  /v1         LLM 게이트웨이 (가상 키 hx-…) · OTLP 수신(/v1/logs, /v1/metrics)
  /mcp        MCP 허브 (Streamable HTTP)
```

Node 런타임을 포함한 설치 패키지 하나로 뜬다. 기본 저장소는 SQLite(파일 하나)이고, 규모가 커지면 PostgreSQL로 바꾼다.

## 화면

왼쪽 메뉴는 하는 일로 묶었다(관리자 22칸, 일반 사용자 13칸). 비슷한 화면은 메뉴 한 칸에 두고 화면 위 **묶음 탭**으로 오간다. 주소는 화면마다 그대로라 알림·북마크가 깨지지 않는다.

### 화면 말과 확인

- **화면 말** — 개발 용어 대신 쓰는 말로 바꿨다(0.9.1). 주소·API·설정 이름은 그대로다.

  | 화면 말 | 예전 말 |
  |---|---|
  | 문서 검색 · 문서함 · 조각 · 의미 색인 | 문서 RAG · 컬렉션 · 청크 · 임베딩 |
  | 사용량·비용 | Insight |
  | 모델 연결 · 경로 규칙 | 프로바이더 · 라우트 |
  | 입력값 | 인자 |

- **되돌리기 어려운 동작은 먼저 묻는다** — AX-NAVI 허가 회수는 "연결된 기기 2대의 연결이 바로 끊깁니다 … 되돌릴 수 없습니다"처럼 결과를 적은 확인 창을 띄운다. 사용자 비활성화도 "더 이상 로그인할 수 없습니다. 사용 기록·감사 로그는 그대로 남고, 언제든 다시 활성화할 수 있습니다"를 보여 주고 묻는다. 끝나면 완료·오류 알림이 뜬다.
- **대시보드의 '어제보다'** — 어제 하루 전체가 아니라 **어제 이 시각까지**와 견준다. 아침에 열어도 숫자가 늘 줄어 보이지 않는다.
- **권한 없는 화면** — 주소로 열면 대시보드로 돌아오고 "권한이 없습니다 — '감사 로그' 화면은 시스템 관리자·감사자만 열 수 있어 대시보드로 왔습니다" 같은 안내가 뜬다.
- **감사 로그** — 기간·사람(이름·ID)·행위 묶음(예: 로그인)·결과로 거르고 쪽을 나눠 본다. 행위·결과·상세는 화면 말로 보이고, 원래 코드는 마우스를 올리면 보인다.
- **키보드와 어두운 화면** — Tab 으로 옮겨 가면 초점 테두리가 보이고, 어두운 화면에서도 빨간 배지 글자가 읽힌다. 비용은 모두 `$` 로 적는다.
