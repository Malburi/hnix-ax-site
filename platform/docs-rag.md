# 문서 검색

운영 매뉴얼, 설계서, API 명세 같은 사내 문서를 올려 두고 질문으로 찾는다. 키워드 검색과 의미 검색을 함께 돌려 순위를 합친다. 메뉴 **AI 통제 › 문서 검색**(0.9.1 전 이름은 '문서 RAG').

## 동작

```mermaid
flowchart LR
    U["문서 올리기<br/>txt·md·html·docx…"] --> X["텍스트 추출<br/>EUC-KR 포함"] --> C["제목 단위 조각"]
    C --> F["FTS5 trigram<br/>키워드 색인"]
    C --> E["의미 색인<br/>게이트웨이 경유"] --> V["sqlite-vec<br/>벡터 색인"]
    Q["질문"] --> F & V
    F --> R["RRF로 순위 합치기"]
    V --> R
```

- **키워드**: FTS5 trigram에 두 글자 낱말 보완 검색을 더했다. 한국어 조사·어미가 붙어도 찾는다.
- **의미 검색**: 조각마다 의미 색인(임베딩 벡터)을 만들어 sqlite-vec 확장(설치 패키지에 포함)에 둔다. 확장이 없으면 직접 계산한다.
- **의미 색인은 게이트웨이를 거친다.** 개인정보 보호, 데이터 등급 경로 규칙, 사용량 계량이 그대로 적용된다. 사내 의미 검색 모델을 쓰면 문서가 밖으로 나가지 않는다.
- 의미 검색 모델을 정하지 않은 문서함은 키워드 검색만 한다.

## 문서함과 권한

- 문서함은 워크스페이스에 속하고, 그 구성원만 검색한다.
- 문서함마다 의미 검색 모델(별칭)과 데이터 등급을 정한다.
- 의미 색인이 빠진 조각은 **빠진 의미 색인 채우기**로 다시 만든다.

## 받는 형식

txt, md, html, csv, json, xml, sql, 소스 코드, docx(EUC-KR 포함), PDF(한글 글꼴 포함, 쪽마다 절), 한글(HWP 5.0·HWPX). 암호가 걸린 문서와 글자 층이 없는 스캔 PDF 는 이유와 함께 거절한다(OCR 없음).

## 고친 문서 다시 올리기 — 새 버전으로 바꾸기

매뉴얼을 고쳐 같은 파일 이름으로 다시 올리면 화면이 묻는다. **새 버전으로 바꾸기**를 고르면 새 문서를 다 넣은 뒤 이전 버전을 지운다 — 이전 버전이 남아 채팅·현업 창구 답변 근거에 옛 내용이 섞이던 문제를 막는다. **따로 추가**를 고르면 둘 다 남긴다. 내용이 완전히 같은 파일은 예전처럼 거절한다.

문서 목록에는 이름마다 **최신 버전 한 줄**만 보인다. 이전 버전이 있으면 제목 앞에 '이전 버전 2개' 표시가 붙고, 왼쪽 ▸ 를 눌러 펼쳐 본다. 이전 버전도 검색 근거에 섞일 수 있어 지우기를 권한다. 조각 칸의 `12/12` 는 나눈 조각 수 중 의미 색인이 된 수다.
