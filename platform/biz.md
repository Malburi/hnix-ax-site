# 업무 시스템 연결 — ERP·CRM·그룹웨어를 도구로

에이전트와 자동화 흐름이 사내 업무 시스템을 쓰게 하려면, 그 시스템의 API를 **MCP 허브 도구**로 만들어야 한다. 업무 시스템 연결은 연결 정보만 넣으면 도구를 만들어 허브에 등록한다. 그 뒤로는 다른 도구와 똑같이 허브의 정책·승인·감사를 지난다. 메뉴 **현업·연동 → 업무 시스템 연결**(관리자).

## 종류

| 종류 | 인증 | 도구 |
|---|---|---|
| SAP (OData v2·v4) | 계정(Basic) 또는 OAuth2, 쓰기 전 CSRF 토큰 | 엔터티 집합 목록 · 조회(`$filter`·`$select`) · 한 건 · 함수 호출(등록한 이름만) · 만들기 · 고치기 |
| Salesforce | OAuth2 앱 인증 | SOQL 조회 · 레코드 한 건 · 만들기 · 고치기 |
| Microsoft 365 (Graph) | 앱(클라이언트) 인증 | 일정 조회 · 메일 보내기(보낼 수 있는 사람 제한) · Teams 채널 메시지 |
| 네이버웍스 | Service Account(서명 키) 또는 발급한 토큰 | 봇 메시지(사용자·채널) · 구성원 목록 · 구성원 한 사람 |
| 일반 REST (OpenAPI) | 없음 · Basic · Bearer · API 키 헤더 · OAuth2 | OpenAPI 문서를 읽어 고른 operation 마다 도구 하나 |

같은 종류도 여러 개 연결할 수 있다(예: `sap_hr`, `sap_fi`). 연결 이름이 도구 이름 앞에 붙는다(`sap_hr__query`).

## 연결하기

1. **종류**를 고른다.
2. **주소·인증** — 사내 주소와 연동용 계정·앱 정보. 비밀번호·비밀값은 마스터 키로 암호화해 시크릿 저장소에 두고 화면에 다시 보여 주지 않는다.
3. **연결 시험** — 가벼운 호출로 주소·인증·권한을 확인한다(SAP 는 서비스 문서, REST 는 지정한 경로).
4. **도구·정책** — 쓸 도구를 켜고 도구마다 기본 정책을 고른다. **조회는 허용, 업무 시스템에 쓰는 도구는 승인 필요**로 시작한다. 차단도 있다.
5. 저장하면 허브에 서버(관리 주체: 업무 시스템 연결)와 도구가 등록된다.

연결을 끄면 그 도구를 아무도 못 쓰고, 지우면 도구·기본 정책·비밀값이 함께 지워진다. 관리자가 MCP 허브에서 따로 만든 정책이 기본 정책보다 먼저 적용된다.

## 안전장치

- **승인 필요** 도구는 부를 때마다 다른 관리자가 승인함에서 승인해야 같은 입력값으로 한 번 실행된다.
- 응답 상한(KB)·목록 최대 건수·시간 제한·읽기 재시도(기본 2회)를 연결마다 정한다. 실패한 쓰기는 다시 보내지 않는다.
- 토큰은 만료 전에 갱신하고, 401 이면 토큰을 새로 받아 한 번 더 보낸다(401 은 처리되지 않은 요청이라 쓰기도 포함).
- Microsoft 365 메일은 '보낼 수 있는 사람'(보낸 사람 계정)을 정하면 그 계정으로만 보낸다.

## 현장에서 확인할 것

- Microsoft 365 의 Teams 채널 메시지는 앱 권한만으로는 막혀 있는 회사가 많다. 채널 웹훅 방식이 필요할 수 있다.
- SAP 는 연동 계정의 권한(조회 전용 롤)을 먼저 받는다. 함수 호출은 쓸 함수 이름을 연결에 등록해야 켜진다.

## API

`/api/v1/biz/catalog` · `/connections`(목록·만들기·고치기·켜고 끄기·지우기) · `/test` · `/connections/<id>/test` · `/openapi/parse`
