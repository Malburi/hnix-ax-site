# 분석 — 차트·대시보드·AI 분석

데이터로 바로 차트·표·대시보드를 만들고, 말로 물어 표·차트로 받는다(0.5.0, 화면 다듬기 0.5.1, 차트 엔진 교체 0.5.2). 결과는 저장하지 않는다 — 분석·대시보드·예약 발송은 **열(보낼) 때마다 그 사람 권한으로 다시 조회**한다. 공유는 '보는 길'만 열 뿐이라, 권한 밖 표는 그 사람에게 오류로, 가린 열은 가린 값으로, 행 제한은 그 사람 소속으로 걸린다.

<video controls preload="metadata" poster="video/features/datalake-5.jpg" src="video/features/datalake-5.mp4" style="width:100%;border-radius:10px"></video>

> SQL 결과 → 차트 · 대시보드(필터·피벗·객체 목록·바로 묻기) · AI 분석(지표 근거·이어 묻기) · 지표·차원·확인된 질문 · 객체 분석 · 분석가 화면(2분 21초)

| 기능 | 하는 일 | 누가 |
|---|---|---|
| 차트 만들기 | SQL 작업창 결과의 '차트' 탭, 카탈로그 '차트로 보기'. 막대·선·면적·원·산점도·히트맵·**트리맵·깔때기·게이지·상자 그림**·숫자·표·**피벗**. '묶어서 보기'를 켜면 서버가 원래 SQL 을 감싸 다시 묶는다 — 원본이 수백만 행이어도 정확한 합계, 결과가 200행을 넘으면 처음부터 묶는다 | 모두 |
| 저장된 분석 | SQL·차트 설정을 저장(결과 아님). 사람·역할·소속·모두에게 보기/고치기 공유 | 모두 |
| 대시보드 | 타일(차트·숫자·표·피벗·글·**객체 목록 + 액션**), 공통 필터, 초안 → 게시, 예약 발송, 엑셀·PNG, 사내 포털 끼우기, 대시보드에 바로 묻기 | 모두(게시는 고칠 권한) |
| 지표·차원 | '장애 건수 = count(*)', '평균 해결 시간 = avg(minutes_to_resolve)' 같은 정의와 묶는 기준. 표를 고르면 규칙 + AI 초안, 저장할 때 실제로 한 번 돌려 확인. **확인된 질문**(사람이 확인한 질문 + SQL) | 데이터 엔지니어 |
| AI 분석 | 말로 묻고 표·차트·설명으로 받기, 이어 묻기. MCP 도구 `ask` 로 에이전트도 같은 길 | 모두 |
| 객체 분석 | 온톨로지 객체를 조건으로 골라 속성별·기간별로 세고, 목록에서 바로 액션 | 모두 |

## 차트 만들기

<figure><img src="img/datalake-chart.png" alt="SQL 작업창 차트 탭 — 900행 장애의 해결 시간을 등급별 주 단위로 묶은 선 차트"><figcaption>SQL 결과 900행 → 차트 탭이 처음부터 '묶어서 보기'. 시간 단위를 주로 바꾸면 서버가 다시 묶는다. 가로축·값·계열·집계도 바꾸는 대로 다시 묶는다.</figcaption></figure>

- 결과 모양으로 차트를 먼저 고른다 — 한 행·한 숫자면 숫자 카드, 시각 + 숫자면 선, 글자 + 숫자면 막대, 숫자 둘이면 산점도.
- `incident_id`·`order_no` 같은 키·번호 열은 숫자라도 값 후보에서 뺀다('incident_id 합계'는 뜻이 없다). 값으로 쓸 숫자가 없으면 행 수를 센다.
- 시각 열을 막대로 그리면 일·월·연 단위 칸으로 나눈 축에 그려 막대가 가는 선이 되지 않고, 계열을 나란히 놓는다.
- 표·차트의 열 머리는 카탈로그·지표·온톨로지에 적힌 **한글 이름**으로 보인다(`minutes_to_resolve 평균` → '해결까지 걸린 분 평균'). 원래 열 이름은 마우스를 올리면 보이고, 빈 값(NULL)은 `-` 로 적는다. 이름표는 `GET /api/v1/catalog/labels`.
- 그리는 동안 '차트를 그리는 중…'이 보이고, **저장**·**대시보드에 추가** 단추는 표·차트 어느 탭에서나 보인다.
- 차트는 **ECharts** 로 화면(캔버스)에서 그린다(0.5.2). 저장하는 것은 '종류·가로축·값·계열·집계' 같은 차트 설정뿐이라 식을 실행하지 않고, `eval` 을 막은 보안 정책(CSP)을 그대로 둔다. 화면 테마(밝게·어둡게)를 따라 색이 바뀐다.
- 0.5.1 까지 저장한 차트(Vega-Lite 사양)는 열 때 새 설정으로 바뀐다. 바꿀 수 없는 옛 차트는 표로 보이고 '이전 형식 차트 — 다시 저장해 주세요'가 뜬다.
- 시간 축의 **끝 칸이 지금이 든 기간**(이번 주·이번 달)이면 빗금·점선과 '집계 중'으로 표시해, 아직 덜 쌓인 칸을 급감으로 읽지 않게 한다.
- 상자 그림은 묶지 않은 원래 행으로 그린다 — 가운데 선이 중앙값, 상자가 가운데 50%, 점은 튀는 값이다.
- 피벗은 '행 · 열 · 값 · 집계'를 고르면 서버가 묶어 넓은 표로 바꾼다(열 60개까지).

## 대시보드

<figure><img src="img/datalake-dashboard.png" alt="대시보드 장애 현황 — 건수·평균 해결 시간·P1 숫자 카드, 일별 등급별 면적 차트, 시스템별 막대"><figcaption>'장애 현황' — 숫자 카드, 일별 등급별 면적, 시스템별 막대, 시스템 × 등급 피벗, 최근 P1 장애 목록(바로 진단 요청). 위에 업무 시스템·등급 필터.</figcaption></figure>

- **필터** — 타일 결과에 있는 **열을 고르면** 필터가 만들어진다. 시각 열은 기간, 숫자 열은 숫자, 값이 50개 이하인 글자 열은 고르기 필터가 되고, 그 열이 있는 타일을 타일 SQL 을 감싸 거른다. '상위 5곳'처럼 개수를 자른 타일은 자른 결과 안에서 거르므로, 자르기 전에 거르려면 **고급**에서 타일 SQL 에 `{{이름}}` 자리를 직접 둔다(기간은 `{{이름.from}}`·`{{이름.to}}`). 값은 종류별로 검사해 리터럴로만 넣는다. 예: `WHERE ({{system}} IS NULL OR system = {{system}})`.
- **타일 조작** — 타일의 **⋯ 메뉴**에서 앞·뒤로 옮기기, 너비·높이, 대시보드에서 빼기.
- **편집 보호** — 고치다가 다른 화면으로 가거나 편집을 끝내면 "저장하지 않은 변경이 있습니다"로 묻는다(**계속 고치기** / **저장하지 않고 나가기**). 예약 발송 삭제도 먼저 묻는다.
- **초안과 게시** — 고칠 수 있는 사람은 초안을, 보기만 공유받은 사람은 게시본을 본다. 게시하지 않은 변경은 표시된다.
- **보는 사람 권한** — 같은 대시보드를 HD01 분석가가 열면 HD01 행만 보인다. 볼 수 없는 표를 읽는 타일만 실패하고 나머지는 그린다. 같은 사람·같은 조회는 5분(`analysis.cacheSeconds`) 동안 결과를 다시 쓴다.
- **넓은 공유는 조심스럽게** — 대외비·기밀 표를 읽으면 역할·소속·모두에게 여는 것은 관리자만 할 수 있다.
- **예약 발송** — 매일·매주 정한 시각에 구독한 사람 권한으로 게시본을 돌려 웹훅(JSON + 요약 글)으로 보낸다. 보낼 주소는 `analysis.deliveryUrls` 로 허용한다.
- **사내 포털 끼우기** — `/embed/dashboards/<id>`(메뉴 없음). 끼울 포털 주소는 `server.frameAncestors`.

## AI 분석

<figure><img src="img/datalake-analyze.png" alt="AI 분석 — 확인된 질문으로 답한 시스템별 장애 건수 막대 차트, 사내 모델이 지표 평균 해결 시간을 써서 만든 답"><figcaption>'시스템별 장애 건수'는 확인된 질문이라 모델 없이 그 SQL 로, '등급별 평균 해결 시간'은 사내 모델이 지표 '평균 해결 시간'을 그대로 써서 SQL·차트를 만들었다.</figcaption></figure>

1. 확인된 질문과 거의 같은 질문이면 모델을 부르지 않고 그 SQL 을 쓴다 — 같은 질문에 같은 답.
2. 아니면 질문과 가까운 **지표·차원**과 테이블 구조(값 없이)를 플랫폼 LLM 게이트웨이의 사내 모델에 보내 SQL 과 차트를 받는다. 지표의 집계식은 바꾸지 않게 한다.
3. 만든 SQL 은 사람 SQL 과 똑같이 권한·가림·행 제한을 지난다. 차트가 결과 열과 안 맞으면 결과 모양으로 고른다. SQL 오류는 한 번 고쳐 쓴다.
4. 이어 묻기('시스템별로 나눠서')는 앞 SQL 3개를 맥락으로 보낸다. 대시보드에서 물으면 그 대시보드의 타일 SQL 을 힌트로 준다.

기다리는 동안 "분석 중… 12초"처럼 걸린 시간이 보이고(표가 크거나 질문이 길면 1분쯤), **그만 묻기**로 멈추거나 답을 못 받았으면 **다시 묻기**로 같은 질문을 다시 보낸다. 모델이 만든 답에는 **AI 가 만든 답 · 확인 필요** 표시가 붙는다.

작은 사내 모델일수록 지표·확인된 질문이 정확도를 크게 올린다. 자주 묻는 질문은 확인된 질문으로 등록해 둔다.

## 객체 분석

<figure><img src="img/datalake-object-analysis.png" alt="객체 분석 — 장애를 등급별로 센 막대 차트와 장애 목록, 진단 메모·진단 에이전트 요청 버튼"><figcaption>온톨로지 '장애'를 등급별로 세고, 오른쪽 목록에서 바로 액션(진단 메모 남기기·진단 에이전트 요청 — 승인이 필요한 액션은 승인 흐름 그대로).</figcaption></figure>

조건(같음·포함·중 하나·비어 있음 등)으로 객체 묶음을 고르고, 속성별·기간별(일·주·월·분기·연)로 센다. 목록을 대시보드 타일로 붙이면 '목록 + 차트 + 액션'의 작은 업무 화면이 된다.

## 분석가 첫 화면

분석가가 로그인하면 **한눈에 보기**가 레이크 상태 대신 분석 화면으로 열린다(엔지니어·관리자는 예전처럼 시점·용량·수집 상태).

- **데이터에 무엇이든 물어보세요** — 질문을 쓰고 **질문하기**를 누르면 AI 분석으로 간다. 아래에 확인된 질문이 '확인된 질문 — 바로 답합니다:' 꼬리표로 보인다.
- **내 대시보드** · **최근 분석** — 공유받거나 만든 것 최근 6개씩. 화면이 스스로 만든 조회는 '내 최근 조회'에 섞이지 않는다.

<figure><img src="img/datalake-analyst-home.png" alt="분석가 첫 화면 — 데이터에 무엇이든 물어보세요 질문 칸, 내 대시보드, 최근 분석, 왼쪽 메뉴의 객체 탐색"><figcaption>분석가(HD01)의 첫 화면 — 질문 칸, 공유받은 대시보드, 최근 분석. 왼쪽 메뉴에 '객체 탐색'.</figcaption></figure>

좁은 화면(900px 이하)에서는 왼쪽 메뉴가 ☰ 서랍으로, 테마·비밀번호·로그아웃은 ⋯ 안으로 들어간다. 테마는 AX Platform 과 같은 규칙이라 어두운 화면에서도 배지 글자가 읽히고, Tab 으로 옮기면 초점 테두리가 보인다.

## API·에이전트

| 하는 일 | API |
|---|---|
| 결과를 다시 묶기·피벗 | `POST /api/v1/analysis/aggregate {sql, spec}` |
| 저장된 분석 | `GET/POST /api/v1/analyses`, `POST /api/v1/analyses/<id>/run`, `PUT …/shares` |
| 대시보드 | `GET/POST /api/v1/dashboards`, `PUT /api/v1/dashboards/<id>`, `POST …/publish`, `POST …/run {filters}`, `…/subscriptions` |
| 지표·차원·확인된 질문 | `GET /api/v1/semantic`, `PUT /api/v1/semantic/metrics`·`/dimensions`, `POST /api/v1/semantic/draft`·`/verified` |
| AI 분석 | `POST /api/v1/analyze {question, history?}` · MCP 도구 `ask` |
| 객체 분석 | `POST /api/v1/ontology/types/<유형>/aggregate` · `/objects` |
| 엑셀 | `POST /api/v1/export/xlsx` |

통합 점검: [E2E 꾸러미](/getting-started/e2e-kit.md)의 ㉔(지표·차원 → 대시보드 게시·공유 → 엔지니어 900건 / 분석가 300건, 필터·피벗·엑셀), ㉕(확인된 질문은 모델 없이, 새 질문은 지표를 근거로 사내 모델, 허브의 `datalake__ask`)가 실제로 돈다.
